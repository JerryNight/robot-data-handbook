# 00 · 心智模型

在读任何具体技术之前，先建三张地图：**数据长什么样、系统分几层、术语怎么对应**。

跳过这一章直接读传感器或 VLA，会遇到典型的"每个词都查了但还是不懂"——因为缺的是结构，不是词汇量。

## 本章文章

| 文章 | 内容 | 读完能回答 |
|---|---|---|
| [what-is-robot-data.md](what-is-robot-data.md) | 机器人数据的四种形态（observation / action / state / metadata），与互联网数据的五个本质差异 | 为什么"转成 Parquet 进数据湖"这个方案会失败 |
| [the-stack.md](the-stack.md) | 机器人系统五层栈（物理 / 驱动 / 中间件 / 算法 / 学习），各层产生的数据与时间语义 | 为什么图像和关节角会差 40 ms |
| [analogies.md](analogies.md) | 软件工程概念 ↔ 机器人概念映射表，含 5 个错误类比的警告 | ROS 2 / TF2 / rosbag 到底像什么 |

## 建议阅读顺序

按上表顺序读，三篇有依赖关系：

```
what-is-robot-data  →  the-stack  →  analogies
   （数据是什么）      （数据从哪来）   （怎么用已知概念理解）
```

第一篇讲"有哪些数据"，第二篇讲"这些数据在哪一层产生、带什么误差"，第三篇讲"怎么把它们挂到你已有的认知上"。顺序反了会看不懂。

## 读完该记住的三件事

1. 机器人数据的核心难点是**对齐**，不是存储。
2. 时间戳的精度上限由硬件决定，软件层补救不了。
3. 动作空间没有版本协商机制，这是跨本体复用的根本障碍。
