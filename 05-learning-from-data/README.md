## 一个关键的映射关系

数据的形态决定了能用的方法，反过来也成立：

| 数据条件 | 适合的方法 |
|---|---|
| 少量高质量演示（< 100 条/任务） | 行为克隆 / ACT |
| 演示质量参差、有失败样本 | 加权 BC、筛选后训练 |
| 有仿真环境 | RL + sim2real（成本可能更低） |
| 大规模多本体数据 | 预训练通用策略（VLA 路线） |

**新手的常见误判**：以为算法选对了就能好用。实际上绝大多数失败来自数据——动作空间定义不一致、控制频率对不上、演示质量不过关。
