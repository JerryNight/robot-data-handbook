## 四个尚未解决的问题

### 1. 采集成本

真机演示的综合成本（布景 + 遥操作 + 重置 + 质检）在几十到上百元/条的量级。要上到百万级数据，必须有数量级的成本下降。

可能的方向：更便宜的遥操作硬件、仿真生成 + 真机微调、从视频中学习（无需动作标注）。

### 2. 跨本体复用

不同机器人的动作空间语义不同，直接合并数据会引入噪声。目前的做法是统一到末端执行器增量位姿，代价是丢失关节层信息（而关节层信息恰恰对力控任务重要）。

这是一个**表示层**的问题，谁先解决谁就能吃到规模红利。

### 3. 自动质量判定

"这段演示成功了没有"目前靠人看。规模化必须做到自动判定，可行路径：仿真重放、VLM 判定、基于状态的启发式检测。

难点在于：机器人任务的成功标准本身是模糊的（杯子放进去了但歪了算不算成功？）。

### 4. 评测基准

真机评测没有统一标准，各论文各说各话。仿真基准（LIBERO、SimplerEnv）和生产环境差距大。没有可靠评测，就无法判断数据质量提升是否真的有用。

## 这个仓库的立场

> 数据平台的价值不在于"存了多少数据"，而在于"能多快地把物理世界的行为变成可训练的信号"。

围绕这句话设计的每一个环节，才是有意义的。
