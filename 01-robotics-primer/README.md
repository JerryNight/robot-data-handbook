# 01 · 机器人最小集

只为读懂数据服务，不做完整机器人学。

这一章的目的不是让你会造机器人，而是让你在看到一个数据字段 `qpos[7]`、一个 `base_link → wrist_3_link` 的变换时，知道它在物理上指什么。

## 计划中的文章

| 文章 | 要回答的问题 |
|---|---|
| `dof-and-joints.md` | 自由度是什么？关节空间和笛卡尔空间差在哪？为什么这个区别影响动作定义 |
| `coordinate-frames.md` | 坐标系为什么需要一棵树？TF2 怎么维护时间维度？URDF 里的 link 和 joint |
| `kinematics.md` | 正/逆运动学各解决什么？雅可比和奇异性如何污染数据 |
| `control-101.md` | 位置/速度/力矩控制有什么本质区别？你的数据是在哪一层记录的 |

## 为什么这章不能跳

跳过坐标系，后面所有多传感器数据都对不齐。这是新手最常见的坑，而且症状是"数据看起来很怪"而不是报错。

详见 [ROADMAP](../ROADMAP.md)。
