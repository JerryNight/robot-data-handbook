> **本仓库的核心章节。** 从一个原始录制的数据包，到能直接喂给训练的数据集，中间要做的全部事情。

## 一条流水线的标准形态

```
采集 → 质检 → 时间对齐 → 标定校正 → 格式转换 → 标注 → 版本化 → 训练 / 评测 → 回流
```

每一环都可能成为瓶颈。实践中最容易被低估的是**质检**和**回流**——前者决定数据能不能用，后者决定平台是不是只是个单向漏斗。

## 常见错误清单

- 假设各传感器频率是整数倍关系（实际不是，会累积漂移）
- 用系统时钟给传感器数据打时间戳（有毫秒级抖动和跳变）
- 把「录制成功」当「数据可用」，跳过回放质检
- 标定信息只存在采集机器的本地配置里，没进数据集
- 单视图标定后直接相信输出的焦距值
- 用 `ORDER BY timestamp` 检查时钟异常（跳变后顺序会乱，必须按写入顺序）
- 以为视频是「无损压缩的原始数据」——丢掉的细节不可恢复
