## 先记住一个结构

几乎所有 VLA 都是这个三段式：

```
图像 + 语言指令  →  [视觉编码器] → [语言/推理主干] → [动作头] → 动作序列
```

分歧全在最后一段：

- **离散 token**：把动作切成 bin，当词表预测。复用 LLM 的交叉熵损失，实现最简单，但精度受量化限制。
- **连续回归**：直接回归连续值，精度好，但容易塌缩到均值，丢失多模态性。
- **生成式（diffusion / flow matching）**：建模动作分布，能表达"多条合理路径"，是目前主流方向。

## 为什么说瓶颈在数据

模型结构正在收敛，但数据侧的三个问题一直没解决：

1. **真机数据太贵**：百万级 episode 的采集成本是千万级
2. **跨本体不可直接复用**：动作空间语义不统一
3. **没有可靠的自动评测**：成功与否还得靠人看
