## 阅读这些数据集时要问的问题

不管看哪个数据集，先回答这五个问题，就能判断它适不适合你：

1. **动作空间是什么？** 关节位置、末端增量、还是离散 token
2. **频率是多少？** 训练时的控制频率必须和数据一致
3. **有没有成败标注？** 没有的话只能做纯 BC，无法做筛选
4. **语言指令是人工写的还是模板生成的？** 模板生成的多样性极差
5. **标定信息在不在包里？** 不在的话跨本体复用基本无望
